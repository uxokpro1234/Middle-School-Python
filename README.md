# Old Python School Projects(ANYWAY I PERFERED JAVA)

A collection of my early Python programs from when I was learning the fundamentals of programming.

These projects are simple, but they cover a surprising amount of the basic programming concepts that I later built upon in more advanced projects.

> **From printing `@` symbols to working with arrays and algorithms. Every programmer starts somewhere.** 😭

---

## What We Learned

### Functions

Learning how to organize code into reusable functions using:

```python
def function_name(parameter):
    ...
    return result
```

Topics covered:

* Function definitions
* Parameters
* Return values
* Calling functions

---

### Loops

Using `for` loops and `range()` to repeat operations:

```python
for i in range(N):
    print(i)
```

Topics covered:

* `for` loops
* `range()`
* Repeating operations
* Iterating through collections

---

### Arrays / Lists

Working with Python lists and accessing individual elements:

```python
A = [0] * 10
A[0] = 42
```

Topics covered:

* Creating lists
* List indexing
* Accessing elements with `A[i]`
* Filling arrays with values
* Iterating through arrays

---

### Random Number Generation

Using Python's `random` module:

```python
from random import randint

number = randint(10, 90)
```

Used for generating random values and filling arrays with test data.

---

### Searching

Implementing basic linear searching by checking each element of an array:

```python
for i in range(N):
    if A[i] == B:
        print("Found!")
```

This introduced the basic idea of searching through a collection element by element.

---

### Strings

Learning how to work with text and string operations:

```python
text = str(number)
length = len(text)
```

Topics covered:

* `str()`
* `len()`
* String concatenation
* Building strings character by character

---

### Type Conversion

Converting between different Python data types:

```python
number = int(input())
text = str(number)
```

Examples:

* `int()` — convert to an integer
* `str()` — convert to a string

---

### Binary Representation

Learning how numbers can be represented in binary:

```python
binary_number = bin(N)
```

The program could convert a decimal integer into its binary representation and count the number of symbols.

Example:

```text
10 → 0b1010
```

---

### Output Formatting

Learning how Python controls console output:

```python
print("@", end="")
```

and:

```python
print("A[", i, "]=", sep="")
```

Topics included:

* `end=""`
* `sep=""`
* Formatting console output
* Drawing simple patterns with characters

---

## Algorithmic Thinking

Even these small programs introduced the basic structure of an algorithm:

```text
INPUT
  ↓
PROCESS
  ↓
OUTPUT
```

For example, one of the array exercises followed this process:

```text
Generate random numbers
        ↓
Store them in an array
        ↓
Ask the user for a number
        ↓
Search through the array
        ↓
Report whether the number was found
        ↓
Display the array
```
